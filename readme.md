# 🧮 Calculator Project (HTML, CSS & JavaScript)

📌 **Project Overview**  

This project is a **web-based scientific calculator** created using **HTML5, CSS3, Bootstrap, and JavaScript** as part of javascript assignment.  

The objective was to build a fully functional calculator that supports basic arithmetic, advanced mathematical functions, memory operations, and keyboard input.

🎯 **Objectives**  

- Implement interactive functionality with JavaScript  
- Build a scientific calculator with input validation  

🛠️ **Technologies Used**  

- HTML5  
- CSS3  
- Bootstrap 5  
- JavaScript (ES6)  

✨ **Features Implemented**  

- ✅ Basic arithmetic operations ( +, -, ×, ÷, %, ** )  
- ✅ Advanced mathematical functions (log, ln, sin, cos, tan, square, square root, factorial, reciprocal, absolute, exp, constants π & e)  
- ✅ Memory operations (store, recall, add, subtract, clear)  
- ✅ Toggle positive/negative sign  
- ✅ Input validation to prevent invalid expressions  
- ✅ Keyboard support for numbers and operators  
- ✅ Responsive layout

- Download or clone the repository
