# 📝 CRUD Assignment (HTML, CSS & JavaScript)

📌 **Project Overview**  

This project is a **web-based CRUD (Create, Read, Update, Delete) application** built using **HTML5, CSS3, and JavaScript** as part of javascript CRUD assignment assignment.  

The objective was to implement a fully functional CRUD system with data management features like adding, updating, deleting, filtering, and sorting items in a structured interface.

🎯 **Objectives**  

- Implement dynamic functionality with JavaScript  
- Build a CRUD system for managing data  

🛠️ **Technologies Used**  

- HTML5  
- CSS3  
- JavaScript (ES6)  
- Bootstrap 

✨ **Features Implemented**  

- ✅ **Add Items:** Users can add new records dynamically  
- ✅ **Update Items:** Edit existing records easily  
- ✅ **Delete Items:** Remove items from the list  
- ✅ **Filter Items:** Search or filter items based on productname, productprice, productid  
- ✅ **Sort Items:** Sort items by id
