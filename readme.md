# 🛒 Flipkart Homepage Clone (HTML & CSS)

## 📌 Project Overview

This project is a **Flipkart Homepage Clone** created using **HTML5 and CSS3** as part of my frontend development assignment.

The objective was to recreate the homepage layout of Flipkart to practice structuring web pages and designing user interfaces using only HTML and CSS.

---

## 🎯 Objectives

- Practice HTML page structure
- Apply CSS styling techniques
- Use Flexbox for layout alignment
- Design a clean and structured homepage
- Improve frontend development skills

---

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- Flexbox  
- Grid
- Media Queries 

---

## ✨ Features Implemented

- ✅ Navigation bar with logo and search bar  
- ✅ Login, Cart and Menu section  
- ✅ Category section  
- ✅ Banner/Slider section  
- ✅ Product display sections  
- ✅ Clean and responsive layout
